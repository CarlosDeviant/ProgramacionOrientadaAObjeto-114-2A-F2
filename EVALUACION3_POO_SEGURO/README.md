# Evaluación 3 — Programación Orientada a Objeto Seguro (POO)

Estructura solicitada: cada ejercicio tiene su carpeta, sus clases en `clases/` y su ejecución parte desde `main.py`. (Ver rúbrica) 

## Cómo ejecutar (Windows / Linux / macOS)

En una terminal, entra a la carpeta del ejercicio y ejecuta:

```bash
python main.py
```

Ejemplos:

```bash
cd ejercicio1
python main.py
```

```bash
cd ejercicio2
python main.py
```

## Notas
- Cada ejercicio incluye **interacción con el usuario** (menú simple).
- Se usa **herencia** mediante una clase base `ArchivoJSON` para guardar/cargar datos en JSON.
- Hay pruebas incluidas: 
  - Ej1: registra destinos y envía 2 mensajes
  - Ej2: carga 12 estadías de ejemplo y genera reporte
  - Ej4: registra sensores, simula lecturas y genera reporte
